## Agent skills

### Issue tracker

Issues live in local Markdown under `.scratch/`, which is gitignored. Before reading, creating, or updating issues or wayfinder maps, read `docs/agents/issue-tracker.md`.

### Triage labels

Use the five default triage labels. Before triaging issues, read `docs/agents/triage-labels.md`.

### Domain docs

Use a single context: root `CONTEXT.md` and `docs/adr/`. Before exploring domain behavior, read `docs/agents/domain.md`.

### Coding conventions

Before implementing or reviewing code, read the accepted ADRs in `docs/adr/` for Solidity conventions, frontend organization, and quality gates.
